# Blessed Raven

Landing rebuild for [www.blessedraven.com](https://www.blessedraven.com).

Full-viewport light page with the sacred-geometry mark (`assets/jakel3726.svg`): quiet breathe on the whole sigil, outer symbols slow-orbit a few degrees while the center stays still. Symbol hotspots link to GitHub, Fund (placeholder), and other `#soon` slots.

`prefers-reduced-motion` disables orbit and breathe.
